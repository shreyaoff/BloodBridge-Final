About Blood Bridge

Blood Bridge is a web-based blood donor management project built using HTML, CSS and JavaScript. It was created to make the process of finding and registering blood donors in Nepal simpler and more organized, compared to relying on scattered social media posts and word of mouth.

The website allows people to register as donors, search for donors by blood group and district, submit a blood request when someone urgently needs blood, and view the full list of registered donors. All data is stored locally in the browser using localStorage, since this project is a frontend prototype without a backend server or database.

This project was built as part of the BCSIT Project I coursework at Malpi International College, under Pokhara University.
